Supermarket Shelf-Stocking Robot

A simulated supermarket robot that searches for products, grasps them from a central goods area, selects suitable shelf cells, and places items onto lower or upper shelves using perception, localization, navigation, and manipulation.

Webots Simulation Mobile Manipulation Vision-Based Grasping GPS / Compass Navigation Pick-and-Place

2Overview

This course project explored how a mobile robot could perform autonomous shelf-stocking tasks in a structured retail environment.

The robot was simulated using Webots and designed as a small mobile manipulator equipped with a gripper, camera-based object recognition, distance sensing, GPS-based localization, and compass-based heading estimation. The task was to let the robot identify products in a central goods area, pick them up, determine an appropriate shelf location, navigate through the supermarket layout, and place each item into the selected shelf cell.

Compared with a simple pre-programmed pick-and-place routine, this project emphasized a more complete task pipeline: product search, visual detection, grasping, shelf selection, autonomous navigation, and placement on both lower and upper shelf levels.

3Robot Platform

The simulated robot was a compact mobile manipulator with an onboard gripper and multiple sensing modules.

Mobile base

A small differential-drive base was used to move around the supermarket aisles and position the robot in front of target shelves.

Manipulator and gripper

The robot used a gripper mechanism to pick up products and place them into shelf cells. The arm configuration was adjusted to support both low-level and high-level placement.

Vision sensing

Camera recognition was used to detect target products and help align the robot before grasping.

Localization sensing

GPS and compass information were used to simplify localization and heading control inside the simulated supermarket.

4Simulation Environment

The supermarket scene was built in Webots with a central goods area and surrounding shelf regions.

The environment contains a central product area where items are initially placed, as well as multiple surrounding shelves. Each shelf contains two vertical levels and multiple cells, allowing the robot to perform both low-shelf and high-shelf stocking tasks. The robot first patrols around the central goods area and uses a side-facing camera to search for products. Once an object is detected near the center of the camera view, the robot turns toward it and switches to the grasping stage.

The shelf system was represented as a set of candidate storage cells. After grasping an item, the robot selected a target cell based on the current shelf occupancy information, then navigated to the selected shelf and executed a placement motion.

5Task Pipeline

The project combined perception, task planning, navigation, and manipulation into a complete shelf-stocking workflow.

Search Patrol around the central goods area
Detect Use camera recognition to locate products
Grasp Align, approach, and pick up the item
Navigate Move to the target shelf cell
Place Stock the item on a lower or upper shelf

During the search stage, the robot moves counterclockwise around the central goods area. When the side camera recognizes a product and the detected object is centered in the visual field, the robot turns approximately 90 degrees toward the object. It then uses front-facing perception and distance information to approach the object, stop at an appropriate grasping distance, and close the gripper.

After grasping, the robot selects a shelf cell from the available storage locations. The navigation behavior considers whether the target shelf is behind, to the side of, or across from the robot, then drives through the corresponding aisle path before executing the placement motion.

6Shelf Selection and Navigation

A simple shelf-memory structure was used to choose where each object should be placed.

The simulated supermarket contains four shelf regions, each with two vertical levels and four cells per level, resulting in 32 possible storage cells. A shelf occupancy array was used to record whether each cell was empty or already assigned to a product category. This allowed the robot to place new items into empty cells or group similar products into existing shelf regions.

Navigation was simplified using GPS coordinates and known shelf positions. Based on the target cell location, the robot selected one of several navigation routines: moving to a shelf on the opposite side, moving to a side shelf, or moving to a shelf behind the robot. This structure made the task logic easier to organize and helped connect high-level shelf planning with low-level motion execution.

7Results

The final simulation demonstrated an end-to-end autonomous stocking behavior in the Webots environment.

The robot was able to search for products, detect and grasp target objects, navigate to selected shelf locations, and complete placement on both lower and upper shelf levels. The project provided hands-on experience with robotic simulation, sensor processing, differential-drive control, camera-based object recognition, task-level decision making, and pick-and-place manipulation.
