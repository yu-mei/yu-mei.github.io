2Overview

Micromouse is a classic robotics competition in which a small autonomous robot must explore an unknown maze, map it, and then complete the shortest possible run from start to center. In this project, the maze-solving algorithms were first validated in Webots simulation and then deployed on a physical robot.

The system integrates wall sensing, motion control, path planning, and real-world autonomous maze navigation — using the simulation to debug the exploration and planning logic before transferring it to hardware.

3System

From perception to a planned fast run, validated in simulation and on hardware.

Wall sensing

Infrared/distance sensors detect walls on the left, front, and right to identify open passages at each maze cell.

Motion control

Closed-loop wheel control keeps the robot centered in each cell and executes precise straight moves and 90° turns.

Maze solving & planning

A flood-fill / shortest-path strategy maps the maze during exploration and plans the fastest route from start to the goal.

Sim-to-real

Algorithms were first verified in Webots, then deployed to the physical robot, reducing debugging effort on hardware.
